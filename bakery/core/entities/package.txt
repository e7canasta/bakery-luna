  Entidades Implementadas                                                                                                                                                                                         
                                                                                                                                                                                                                  
  Frame entities (core/entities/frame.py):                                                                                                                                                                        
  - CropInfo - Immutable crop info (frozen dataclass)                                                                                                                                                             
  - Frame - Video frame with metadata, support for cropping                                                                                                                                                       
                                                                                                                                                                                                                  
  Detection entities (core/entities/detection.py):                                                                                                                                                                
  - BoundingBox - Bounding box with confidence and class ID                                                                                                                                                       
  - Mask - Binary segmentation mask                                                                                                                                                                               
  - Segmentation - Aggregate of detections (bboxes + masks)                                                                                                                                                       
                                                                                                                                                                                                                  
  Pose entities (core/entities/pose.py):                                                                                                                                                                          
  - KeyPoint - Single keypoint with confidence                                                                                                                                                                    
  - Skeleton - 17 COCO keypoints for a person                                                                                                                                                                     
  - PoseEstimation - Aggregate of skeletons                                                                                                                                                                       
  - COCO_KEYPOINT_NAMES - Named keypoint indices                                                                                                                                                                  
                                                                                                                                                                                                                  
  Config entities (core/entities/model_config.py):                                                                                                                                                                
  - ModelConfig - Single model configuration (size, resolution, device, precision)                                                                                                                                
  - PipelineConfig - Complete pipeline configuration (seg + pose + params)                                                                                                                                        
  - Enums: ModelSize, Device, Precision
